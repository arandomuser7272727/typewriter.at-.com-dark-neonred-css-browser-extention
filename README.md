# Typewriter Neon Dark

A Firefox/Zen extension that gives `at4.typewriter.at` a black-and-red theme.

## Added
- Progress dashboard with attempt stats, WPM, accuracy, and tempo charts.
- Date filters, defaulting to the last 30 days; attempt history is cached locally per account.
- Lesson controls to hide the virtual keyboard, pause, and drag the lesson panel.
- Grade colors and dark styling for lesson controls and forms.

## Removed
- Ad-block notice and Typewriter logo.
- Lesson footer links.
- Help and Logout buttons outside the Settings page.
